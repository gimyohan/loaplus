개인정보처리방침

시행일자: 2026년 8월 24일 · 최종 수정일: 2026년 8월 24일

LoaPlus(이하 "서비스")는 로스트아크 이용자를 위한 숙제 관리 대시보드입니다. 본 방침은 서비스가 어떤 정보를 수집하고, 어떻게 이용·보관·삭제하는지 설명합니다.

1. 로그인 시 수집하는 정보

서비스는 Google 로그인(OpenID Connect)만을 이용한 본인 식별 방식을 사용합니다. 로그인 과정에서 Google로부터 전달받아 저장하는 값은 아래가 전부입니다.

  • Google 계정 고유 식별값(sub) 하나만 저장합니다.
  • 이름, 이메일 주소, 프로필 사진 등 그 외의 Google 계정 정보는 서버에 저장하지 않습니다.

2. 서비스 이용 중 생성·저장하는 정보

구분내용
닉네임이용자가 서비스 내에서 직접 설정한 표시 이름
로스트아크 캐릭터 정보이용자가 등록한 캐릭터명을 기준으로 로스트아크 Open API에서 조회한 공개 게임 정보(캐릭터 이미지, 서버, 직업, 아이템 레벨, 전투력 등)
로스트아크 Open API 키이용자가 직접 발급받아 등록한 개인 API 키. AES-256-GCM으로 암호화하여 저장하며, 평문으로 저장하지 않습니다.
숙제/컨텐츠 진행 상태가디언 토벌, 쿠르잔 전선, 낙원, 레이드 등 위젯에서 이용자가 직접 조작한 진행 상태(완료 여부, 휴식 게이지, 티켓/열쇠 수량 등)
통계 및 최근 행위 로그재화 획득량 등 통계 수치, 그리고 직전 행위를 취소할 수 있도록 계정당 최근 200건까지만 보관되는 행위 로그(오래된 로그는 자동 삭제됩니다)
커스텀 위젯 콘텐츠이용자가 대시보드에 직접 추가한 텍스트, 체크리스트, 이미지 URL, 링크 등

3. 쿠키 사용

서비스는 로그인 상태 유지를 위한 세션 쿠키 1종만 사용합니다. 이 쿠키는 httpOnly(자바스크립트로 접근 불가), Secure(HTTPS에서만 전송), SameSite=Lax 옵션으로 설정되어 있으며, 광고나 방문자 추적 목적의 쿠키는 사용하지 않습니다.

4. 제3자 제공 및 외부 API 이용

서비스는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스 기능 제공을 위해 아래와 같이 외부 API를 이용합니다.

  • Google Identity Services: 로그인 시 신원 확인 목적으로만 이용되며, 위 1항의 식별값 외에는 어떤 정보도 전달받지 않습니다.
  • 로스트아크 Open API(스마일게이트): 이용자가 등록한 캐릭터명과 이용자 본인의 API 키를 이용해 해당 게임 계정의 공개 정보를 조회합니다. 이는 이용자 본인의 요청을 대행하는 것이며, 조회 결과가 다른 이용자나 제3자에게 전달되지 않습니다.

5. 보관 기간 및 삭제

  • 이용자는 언제든지 서비스 내 "회원 탈퇴" 기능으로 계정을 삭제할 수 있습니다.
  • 회원 탈퇴 시 위 2항에 기재된 모든 데이터(캐릭터, 진행 상태, 통계, 로그, 커스텀 위젯 등)가 즉시 삭제되며, 별도의 보관 기간 없이 복구할 수 없습니다.
  • 행위 로그는 탈퇴 여부와 무관하게 계정당 최근 200건까지만 보관되며, 초과분은 자동으로 삭제됩니다.

6. 만 14세 미만 아동에 대한 정책

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.
